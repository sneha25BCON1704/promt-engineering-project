# Lecture 6: Cursor AI Refactoring

## Overview
This repository contains the completed work for Lecture 6 of the Prompt Engineering course, focusing on setting up the Cursor IDE environment and organizing project files for code refactoring practices.

## Files Included
* **`factorial.py`**: A Python script designed to compute the factorial of a given integer with input validation.
* **`number_checker.py`**: A Python script containing utility functions to verify whether numbers are even or odd.

## Objective
The primary goal of this assignment was to navigate the Cursor IDE interface, establish a clean local workspace folder (`lec 6 promt eng`), and structure Python modules for iterative code improvements.
