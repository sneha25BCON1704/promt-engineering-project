# Session 2: Three-Step Chain Prompting and Reverse Prompting

## Prompts Used

### Step 1: IDENTIFY
You are a senior C engineer reviewing code written by a 2nd-year engineering student. This program should calculate the average of an integer array and print it as a decimal. List every bug you can find in the code below. Do NOT fix anything yet. Answer as a numbered list with the line number and a one-line description for each bug.

### Step 2: EXPLAIN
For each bug you listed, explain in 2-3 lines: what the program actually does at runtime because of it, and what it was supposed to do. Do not give corrected code yet.

### Step 3: FIX
Now give the corrected version of the full program. Add an inline comment on every line you changed, stating which bug number it fixes. Below the code, state the exact output the corrected program will print.

### Reverse Prompt
Act as a strict senior code reviewer examining the answer you just gave. Find at least two weaknesses in it. Do not defend your previous answer.
